========================================
 MemoApp - スタイリッシュダークメモ帳
========================================

【概要】
PyQt6製のデスクトップメモアプリです。
カテゴリツリー、添付ファイル、編集履歴、バックアップ機能を備えています。


【動作環境】
- OS       : Windows 10/11
- Python   : 3.11以上
- Conda    : Anaconda または Miniconda


════════════════════════════════════════
 セットアップ手順
════════════════════════════════════════

1. Conda仮想環境を作成・有効化
   -----------------------------------------------
   conda create -n memo_app python=3.11
   conda activate memo_app
   -----------------------------------------------

2. パッケージをインストール
   -----------------------------------------------
   pip install -r requirements.txt
   -----------------------------------------------

3. アプリを起動して動作確認
   -----------------------------------------------
   python main.py
   -----------------------------------------------

4. exeファイルにビルド
   -----------------------------------------------
   pyinstaller --onefile --windowed --name MemoApp main.py
   -----------------------------------------------

5. 成果物を確認
   -----------------------------------------------
   dist/MemoApp.exe
   -----------------------------------------------

※ ビルドはWindowsマシン上で行ってください。

════════════════════════════════════════
 データ保存構造
════════════════════════════════════════

設定タブで指定したディレクトリ/
├── notes.json               # メモ本体データ
├── attachments/             # 添付ファイル
└── backups/                 # 自動バックアップ（世代管理）
    ├── backup_20250428_120000/
    │   ├── notes.json
    │   └── attachments/
    └── ...

設定ファイル（アプリ設定）:
  Windows: C:/Users/[ユーザー名]/.memo_app_config.json

 ショートカット一覧
════════════════════════════════════════

【メモ操作】
Ctrl+N      新規メモ作成（New memo）
Ctrl+S      メモを保存（Save）
削除ボタン   選択中のメモを削除（Delete memo）

【テキスト編集】
Ctrl+Z      Undo
Ctrl+Y      Redo
Ctrl+C      Copy
Ctrl+X      Cut
Ctrl+V      Paste
Ctrl+A      Select All

【検索】
Ctrl+F      本文内検索バーを開く／閉じる（Find）
Ctrl+G      全文検索ダイアログを開く（Global search）

※ フォントサイズは設定タブのSpinBoxで変更し「設定を適用」ボタンで反映します。
※ アプリ内の「⌨️ ショートカット」タブでも一覧を確認できます。


════════════════════════════════════════
 主要機能
════════════════════════════════════════

■ カテゴリツリー
  - 初期表示はカテゴリ名のみ
  - クリックでタイトル一覧を展開/折りたたみ
  - タイトル列・更新日時列ヘッダーで昇降順ソート（インジケータ表示あり）
  - 「📁 カテゴリ編集」ボタンで編集ウィンドウを開く
  - 編集ウィンドウで追加・リネーム・削除が可能
  - 右クリックメニューでもカテゴリ編集・削除可能
  - カテゴリ削除時は属するメモを「未分類」に移動
  - 「未分類」は削除・リネーム不可

■ テキストエディタ
  - 行番号表示
  - 本文内検索（Ctrl+F）
  - 全文検索（Ctrl+G）
  - 自動保存（編集後3秒で自動保存）
  - フォントサイズ・フォント種類の変更（設定タブで変更後「設定を適用」ボタンで即時反映）
    ※ フォント設定はスタイルシートを動的に上書きして確実に反映されます
  - 文字数カウント（ステータスバー）

■ 添付ファイル
  - ファイルをattachmentsディレクトリにコピーして保存
  - ダブルクリックでOSデフォルトアプリで開く
  - 「🗑 選択を削除」ボタンまたは右クリック→「削除」で削除（確認ダイアログあり）
  - 右クリック→「開く」でもファイルを開ける

■ 編集履歴
  - 保存のたびにバージョンを記録（デフォルト10世代）
  - 「履歴」ボタンから任意バージョンに復元可能

■ バックアップ
  - 保存時に自動世代バックアップ（デフォルト5世代）
  - notes.json + attachmentsをまとめてバックアップ
  - 手動zipエクスポート対応
  - 設定タブのバックアップ一覧からダブルクリックで復元

■ 設定タブ
  - 保存ディレクトリ指定
  - 読み込むnotes.jsonパス指定
  - 行折り返しON/OFF
  - フォント種類・サイズ（変更後「設定を適用」ボタンでテキストエディタに即時反映）
  - 編集履歴保持バージョン数（デフォルト10）
  - バックアップ保持世代数（デフォルト5）
  - バックアップ一覧・復元

■ ショートカット一覧タブ
  - アプリ内でショートカットキーをいつでも確認可能


════════════════════════════════════════
 注意事項
════════════════════════════════════════

- exeビルドはWindowsで実行してください
- 初回起動時は設定タブで保存ディレクトリを指定してください
- notes.jsonは初回起動時に自動生成されます（手動作成不要）
- バックアップ復元後はアプリが自動的にデータを再読み込みします
- フォントサイズ・種類は設定タブで変更し「設定を適用」を押してください（ショートカットキーによる変更は非対応）
